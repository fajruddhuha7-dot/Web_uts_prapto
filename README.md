## 📌 1. Deskripsi Proyek
Proyek ini adalah website presentasi interaktif berbasis **HTML, CSS, dan JavaScript murni** (tanpa library rumit). Dibuat khusus untuk memenuhi rubrik penugasan UTS Multimedia:
- **Tepat 14 Slide Terstruktur** (tidak kepanjangan, visual to-the-point).
- **3 Studi Kasus Nyata:** Musik (Spotify), Video (Netflix/TikTok), dan Berita (Koran vs Media Digital).
- **2 Elemen Interaktif:** Timeline Garis Waktu dinamis & Kuis Singkat dengan penghitungan skor otomatis.
- **Navigasi Simpel:** Menggunakan tombol di layar dan tombol panah keyboard (`⬅️` / `➡️`).
